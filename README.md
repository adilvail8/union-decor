# Union Decor — лендинг

Статический лендинг для салона напольных покрытий Union Decor (Астана, Туркестан 34/1).
Без сборки и зависимостей: три файла + картинки. Кидается на любой хостинг как есть.

```
index.html          вся разметка
assets/style.css    стили
assets/app.js       калькулятор, рельс декоров, пошаговый подбор, reveal
assets/img/         8 чистых фото (+ raw/ — исходники со стикерами)
FACTS.md            все факты с источниками — правь копирайт только по нему
```

Локально: `python -m http.server 5510` в этой папке.

## Визуальный язык

Editorial Minimalist / Nordic Wood. Три правила, которым подчинён весь CSS:

1. **Одно полотно.** Фон `--canvas: #F4F1EA` не прерывается нигде. Ни одной секции
   с собственной заливкой, никаких полос «белый-серый-белый».
2. **Ни одного контейнера.** Нет карточек, теней, радиусов и плашек.
   Единственный разделитель — волосяная линия `--line`.
3. **Воздух — материал.** Шкала отступов 8 → 136px (density 2/10).

**Шрифты: Prata + Jost.** Дизайн-скилл предлагал пару Bodoni Moda / Jost, но
**у Bodoni Moda нет кириллицы** — русский заголовок откатился бы на системный сериф.
Prata — дидон от Cyreal с кириллицей, тот же люксовый регистр. Проверяйте кириллицу
у любого нового шрифта, прежде чем ставить.

Палитра почти монохромная: графит `#1A1918`, полотно `#F4F1EA`, приглушённый дуб
`#7A6A53` на микродетали. Зелёный остался ровно в одной точке — индикатор «открыто».
Кнопка WhatsApp — графитовая заливка, не зелёный пузырь.

## Что внутри

**Калькулятор метража** — ядро лендинга. Клиент вводит площадь (или размеры комнат),
выбирает покрытие и раскладку, получает метраж с запасом на подрез и ориентировочную
сумму. Кнопка отправляет весь расчёт в WhatsApp готовым текстом — менеджер сразу видит
контекст, а не «здравствуйте, сколько стоит».

Запас на подрез: прямая укладка +5%, «ёлочка» +12%. Это реальное отраслевое правило
(10–15% на ёлочку), и оно же снимает частую претензию «не хватило материала».

**Рельс декоров** — горизонтальная галерея без скроллбара: drag мышью, свайп на тач,
стрелки с клавиатуры, индикатор прогресса. Уходит в правый край экрана, но первая
плитка выровнена по контентной сетке через `--rail-pad` + `scroll-padding-left`
(без второго `scroll-snap` прижимает плитку к краю и съедает отступ).

**Пошаговый подбор** — три мини-вопроса вместо формы с полями. Ответы копятся
в сводку справа и уходят в WhatsApp готовым сообщением. Контакты вводить не нужно.

**Точки входа в WhatsApp** — шапка, hero, калькулятор, каждая позиция каталога,
рельс, секция про сроки, подбор, закреплённая полоса на мобильных. Полей ввода
контактов нет намеренно: в отзывах видно, что люди пишут и звонят.

**Секция «Начистоту» про сроки** — честно разводит «в наличии» и «под заказ».
Это главное слабое место по отзывам (задержки по товару из России), и умолчать
о нём хуже, чем объяснить.

## Появление при скролле — важное про надёжность

Анимация появления сделана **надстройкой, а не условием видимости**. Класс `.js-reveal`
вешает сам JS, и только он включает `opacity: 0`. Без скрипта, при ошибке в нём или
в throttled-вкладке контент просто виден. Плюс страховочный таймер на 3 секунды.

`IntersectionObserver` намеренно **не используется**: он не срабатывает в фоновых
и неотрисованных вкладках, а цена ошибки здесь — пустая страница. Вместо него —
обычная проверка позиции на `scroll` с throttle через `rAF`.

Если будете трогать этот блок — не возвращайте `opacity: 0` в CSS без класса `.js-reveal`.

## ⚠️ Что нужно поправить перед публикацией

1. **Домен.** В `index.html` в `<link rel="canonical">` и `og:image` стоит заглушка
   `https://uniondecor.kz/`. Поменяйте на реальный домен, иначе canonical будет врать,
   а превью в WhatsApp/Telegram не подтянет картинку (og:image должен быть абсолютным URL).

2. **Фото — главная слабость.** Все 8 картинок вырезаны из обложек reels их Instagram:
   640px по ширине, кадры из видео, местами шум. Для лендинга это потолок.
   Нужна нормальная съёмка зала и образцов — хотя бы на телефон, но со светом
   и без наложенных стикеров. Исходники со стикерами лежат в `assets/img/raw/`.

3. **Цены.** Указаны на 17.07.2026 по акции (промо 2ГИС до 30.08.26). Живут в двух местах:
   - карточки каталога в `index.html`
   - объект `PRODUCTS` в `assets/app.js` (нужен калькулятору)

   При изменении править оба. Дата актуальности — в `.pricenote` и подвале.

4. **Согласовать с владельцем.** Формулировки про возврат остатков, бесплатное хранение
   и рассрочку взяты из их же постов и отзывов, но это не официальная оферта.
   Про компенсацию за задержку намеренно НЕ написано — это был частный случай
   из одного отзыва, а не заявленная политика.
